# Vancouver R3 site feasibility

R3 zoning allows small apartment buildings on what were single-family streets, and this tool shows what a given lot can hold under the zoning and building code, including Vancouver's new single egress stair rules.

**Use the tool:** https://yeony7626.github.io/vancouver-r3-feasibility-study/
